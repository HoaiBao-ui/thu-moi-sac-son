THƯ MỜI SẮC SON — BẢN ĐÃ SỬA ĐƯỜNG DẪN

Cấu trúc:
- index.html
- config.js
- script.js
- style.css
- assets/pages/  (đặt đủ 6 ảnh trang ở đây)
- assets/audio/  (đặt nhạc nền ở đây)

QUAN TRỌNG:
1. Copy 6 ảnh từ thư mục pages hiện tại của bạn vào assets/pages/ trong thư mục này.
   Giữ đúng tên:
   01-bia.jpg.jpg
   02-loi-moi.jpg.jpg
   03-gioi-thieu.jpg.jpg
   04-thong-tin.jpg.jpg
   05-loi-nhan.jpg.jpg
   06-ket-thuc.jpg.jpg

2. Copy nhạc vào assets/audio/ với tên nhac-nen.mp3.mp3

3. Tải các file index.html, config.js, script.js, style.css lên thư mục gốc của repository GitHub (ngang hàng với thư mục assets).
   Tải cả thư mục assets lên, không đặt thêm một lớp thư mục thu_moi_sac_son_da_sua ở trong repository.

4. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

5. Mở website và nhấn Ctrl+F5. Nếu không chạy, kiểm tra Console/Network và xác nhận thư viện page-flip CDN có tải được không.

Lưu ý: Các file ảnh và MP3 gốc không được đính kèm trong gói này vì bạn mới gửi 4 file mã nguồn. Hãy chép tài nguyên từ thư mục hiện có của bạn vào đúng thư mục như trên.
